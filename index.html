About the Team

GSS is a three-person team on a mission to become well rounded Java developers. Our journey began with Tailwind CSS, where we sharpened our eye for clean, responsive design. From here, we're moving into Java, JDBC, and Apache Tomcat to understand how the backend brings a web app to life from database connectivity to server deployment. We believe the best way to learn is together, so every project we take on is built collaboratively, with each of us contributing, reviewing, and leveling up as one team.
